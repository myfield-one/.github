# myfield-one/.github

Organization-wide defaults for [myfield-one](https://github.com/myfield-one):

- `profile/README.md`: the organization profile page
- `SECURITY.md` and `CODE_OF_CONDUCT.md`: default policies for every repository
  that does not have its own
- `.github/ISSUE_TEMPLATE/config.yml`: default issue chooser links for
  repositories without their own issue templates

Project overview and feedback live in
[myfield-one/myfield](https://github.com/myfield-one/myfield).
